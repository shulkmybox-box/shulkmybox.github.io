BEDROCK JOIN GUIDE

Bedrock players should use shulkmybox.mcserver.us with port 19132. Console players may need DNS settings or the Better Together app depending on platform.

1

Mobile / Windows Bedrock

Go to Play → Servers → Add Server. Server Address: shulkmybox.mcserver.us. Port: 19132.

2

Xbox / PlayStation / Switch

Consoles usually do not let you freely add servers the same way. Use a DNS method or a helper app such as Better Together / BedrockTogether from your phone to make the server appear on LAN.

3

DNS Method

Change the console DNS to a trusted Bedrock custom server DNS, open Minecraft, then use the server list redirect menu to enter The Box address and port.

4

Better Together App Method

Open the helper app on the same Wi-Fi as your console, enter shulkmybox.mcserver.us and 19132, then join from the Friends/LAN tab on console.

Console Bedrock joining depends on the player’s device, Wi-Fi, and platform restrictions. If one method does not show the server, try the other method or ask in Discord for help.

ADMIN EDITING

This is a static GitHub Pages website, so it cannot have a real private live backend without adding a service like Decap CMS, Netlify, Cloudflare Pages, or a custom server. For now, this pack gives you the easiest safe admin-style editing: change the config.js file and the site updates.

Easy edit file:

config.js

Open config.js in GitHub, click the pencil/edit button, change IPs, links, headline text, or description, then click Commit Changes. That is your simple admin backend for now.


Want a real login admin panel later?

Use Netlify + Decap CMS or Cloudflare Pages + a CMS. GitHub Pages by itself is public static hosting, so it cannot securely save admin edits from a private dashboard without an external backend.
